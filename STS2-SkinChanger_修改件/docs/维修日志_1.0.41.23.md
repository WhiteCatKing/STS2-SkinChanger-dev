# Skin Changer 1.0.41.23 维修日志

基于 1.0.41.22。本版是性能与稳定性维护，不改皮肤识别规则和界面布局。

## 中文

- 修复在 Mod 管理器里禁用卡图 Mod 后卡图仍被接管的问题。扫描卡图包时跳过未加载的 Mod 目录。已选卡图失效时回到游戏默认，存档里的选择保留，重新启用后自动恢复。多个 Mod 挤在同一文件夹且启用、停用混放时，每次启动会弹一次提示，请玩家把它们分开放。
- 切换卡图更快：同一卡图包切走再切回时复用已加载的图集，纹理内存不再逐轮上涨。
- 多档角色（战损、血量档）的皮肤切换后保留已加载的内容，再次切换基本不再重新加载。
- 首次进入选人界面时遗物皮肤加载从约 4 秒降到约 0.2 秒，每局只加载一次。
- 切换皮肤时选包和隔离其他 Mod 补丁的耗时明显降低。
- 同名程序集、内容不同的成对皮肤包（如完整版和精简版）会先加载内容更全的那份，不再因为先选了精简版而缺少战损换装。
- 切换器注入游戏界面的代码出错时只记日志，不再打断其他 Mod 的界面回调。
- 只改文本的事件包保留在下拉里，标为「（仅文本）」，选中时不再联动整包外观。
- 事件图鉴不再为普通事件反复请求不存在的背景场景（每局约 75 条报错）。
- 假商人背景微调快捷键（U/O/I/J/K/L）改为调试用，只在设置环境变量 STS2SC_DEBUG=1 时生效。
- 新增进主菜单后的原版资源只读自检、延迟任务记录和崩溃面包屑，方便排查问题。
- 已通过正式版 v0.111.1 与测试版 v0.114.0 双版本门禁。测试版 v0.114.0 下 BaseLib、RitsuLib 等框架 Mod 尚未更新，游戏需要停用它们才能启动，部分改动仍待在测试版里实机确认。

## English

- Fixed card art from a mod disabled in the Mod Manager still being applied. Unloaded mod folders are now skipped when scanning card art packs. A selected art pack that is no longer available falls back to the game default; the saved choice is kept and comes back when the mod is re-enabled. When several mods share one folder with a mix of enabled and disabled ones, a prompt appears once per launch asking you to separate them.
- Faster card art switching: switching away from a pack and back reuses the loaded atlases, and texture memory no longer grows with each round.
- Multi-stage character skins (damage or HP stages) keep their loaded content, so switching back rarely reloads.
- Relic skins load in about 0.2 s instead of about 4 s on the first visit to character select, and only once per run.
- Pack selection and isolating other mods' patches during a skin switch are much faster.
- Paired skin packs that share an assembly name but differ in content (such as a full and a lite version) now load the fuller one first, so damage-stage outfits no longer go missing when the lite version is picked first.
- Errors in Skin Changer's UI injection code are logged without breaking other mods' UI callbacks.
- Text-only event packs stay in the dropdown marked "(text only)" and no longer pull in the whole pack's visuals.
- The event compendium no longer requests missing background scenes for ordinary events (about 75 errors per run).
- The fake merchant background nudge keys (U/O/I/J/K/L) are now debug-only and work only with the environment variable STS2SC_DEBUG=1.
- Added a read-only vanilla asset self-check after the main menu, deferred task records and crash breadcrumbs for troubleshooting.
- Passed the stable v0.111.1 and beta v0.114.0 gates. On beta v0.114.0, framework mods such as BaseLib and RitsuLib have not been updated yet and must be disabled for the game to start, so some changes still need in-game confirmation on the beta.
