# Skin Changer 1.0.41.23 维修日志

基于 1.0.41.22，主要改善切换性能、界面稳定性和卡图包禁用后的处理。

## 中文

- 修复在 Mod 管理器里禁用卡图 Mod 后卡图仍被接管的问题。放在独立文件夹里的卡图 Mod 禁用后不再应用，卡面会按现有优先级使用其他可用卡图，没有可用卡图时显示游戏默认。重新启用后会恢复原有选择和优先级。启用和停用的 Mod 混放在同一文件夹、并且带有卡图包文件时，卡图可能继续应用，主菜单会提示把它们分开放。
- 修复按卡池分文件夹放置的散图卡图包里，有和其他角色卡池同名的卡时，这张卡被漏掉、图片刚好够数的包会整包不出现在下拉里的问题。没有卡池文件夹、确实分不清是哪张卡的图仍会跳过。
- 切回同一卡图包时，会复用仍在缓存中的图集和散图，减少重复解码和纹理内存累积。
- 多档角色（战损、血量档）的皮肤切回时，可以复用仍在缓存中的图集、骨骼和场景。
- 遗物皮肤会整包缓存。实测故障机器人首次进入选人界面时，遗物资源加载从约 4 秒降到约 0.2 秒，之后再访问可以复用缓存。
- 切换皮肤时选包和隔离其他 Mod 补丁的耗时明显降低。
- 对识别为姊妹包的完整版和精简版，优先加载完整版的行为代码，减少先选精简版时缺失战损换装的情况。
- 为多处界面注入回调和单人、多人开局前的清理增加异常隔离，出错时记录日志，避免打断同一回调链或拦住开局。
- 只改文本的事件包保留在下拉里，标为「（仅文本）」，选中时不再联动整包外观。
- 事件图鉴预览普通事件时，跳过不存在的背景场景，减少重复的资源加载报错；事件本身照常显示。
- 假商人背景微调快捷键（U/O/I/J/K/L）改为调试用，只在设置环境变量 STS2SC_DEBUG=1 时生效。
- 新增进主菜单后的原版资源只读自检、延迟任务记录和崩溃面包屑，方便排查问题。
- 已通过正式版 v0.111.1 和测试版 v0.114.0 的自动检查。测试 v0.114.0 时，我们临时停用了安装环境中尚不兼容的部分框架 Mod，依赖这些框架的场景仍待实机确认。

## English

- Fixed card art from a mod disabled in the Mod Manager still being applied. A card art mod in its own folder is no longer applied once disabled; cards use other available art by your existing priority, or the game default when none is available. Re-enabling the mod restores your original choice and priority. When enabled and disabled mods share one folder that contains card art pack files, the art may still be applied, and the main menu asks you to keep them in separate folders.
- Fixed a loose card art pack organized in per-pool folders missing a card that shares its name with a card in another character's pool; a pack with just enough images could disappear from the dropdown entirely. Images with no pool folder whose card is genuinely ambiguous are still skipped.
- Switching back to the same card art pack reuses atlases and loose images that are still cached, reducing repeated decoding and texture memory build-up.
- Multi-stage character skins (damage or HP stages) can reuse atlases, skeletons and scenes that are still cached when you switch back.
- Relic skins are cached as a whole pack. In testing, Defect's relic resources on the first visit to character select loaded in about 0.2 s instead of about 4 s, and later visits can reuse the cache.
- Pack selection and isolating other mods' patches during a skin switch are much faster.
- For a full and a lite version recognized as twin packs, the full version's behavior code is loaded first, reducing missing damage-stage outfits when the lite version is picked first.
- Added exception isolation to many UI injection callbacks and to the cleanup before starting a single-player or multiplayer run. Errors are logged instead of breaking the same callback chain or blocking the run from starting.
- Text-only event packs stay in the dropdown marked "(text only)" and no longer pull in the whole pack's visuals.
- When previewing ordinary events, the event compendium skips background scenes that do not exist, reducing repeated resource loading errors; the events themselves still display.
- The fake merchant background nudge keys (U/O/I/J/K/L) are now debug-only and work only with the environment variable STS2SC_DEBUG=1.
- Added a read-only vanilla asset self-check after the main menu, deferred task records and crash breadcrumbs for troubleshooting.
- Passed the automated checks on stable v0.111.1 and beta v0.114.0. While testing v0.114.0 we temporarily disabled some framework mods in our install that are not yet compatible, so scenarios that depend on those frameworks still need in-game confirmation.
