# 其它图鉴新增奥斯提、异鸟成鸟和瓦皮

内部版本：1.0.35.1；工坊公开版维持 1.0.35，本次不上传。

## 用户需求与原生依据

用户要求在「生物」分类原有异鸟宝宝、佩尔的士兵之外增加奥斯提、异鸟成鸟和瓦皮。奥斯提须与选人界面显示、保存皮肤和下拉选项保持一致，并提供动作预览。

从实际游戏 DLL/PCK 确认：成鸟使用 ByrdineMonster / creature_visuals/byrdine_monster.tscn，骨架位于 monsters/byrdine；瓦皮使用 Wuppy / creature_visuals/wuppy.tscn。当前简中文本中前者的原生名称为「小异鸟」，本图鉴简繁中文入口按用户要求显示「异鸟成鸟 / 異鳥成鳥」，其余语言使用原生名称。正式版缺少这两个模型，只显示原有两项与奥斯提，避免访问不存在的资源。

## 实现

- OtherCreatureCatalog 登记五个条目；新增两项以实际原生模型类型存在性判断版本能力，不静态引用测试版专属类型。
- OstySkinChoices 是选人界面和生物图鉴的共用列表及写入入口，包括默认、资源皮肤、独立奥斯提包、随机及工坊项。两处均读写同一 companion 配置，选皮肤使用 ApplyCompanionSelection 最小事务，不联动切换主人皮肤。
- 图鉴在打开期间订阅 CompanionSelectionChanged，延迟更新并合并过期请求；关闭和退出树时解除订阅，防止隐藏图鉴残留或重复刷新。
- 奥斯提按选人预览相同优先级创建：作者独立展示工厂 → 可绘制的场景外观 → 当前所选骨架。复用 OstyModelPreviewControls 的资源读取，包含独立包的展示动画；图鉴单独按边界缩放，不修改保存的缩放和停靠状态。
- 奥斯提提供攻击、施法、受击、倒下、复活等动作，瓦皮提供原生受击/倒下，成鸟提供存在时可用的攻击；按钮只显示当前骨架或帧动画实际具有的动作。新动作标签覆盖 15 种语言。
- 通用动作播放补充 AnimatedSprite2D 支持。播放前复制 SpriteFrames，只修改预览副本的循环设置；非循环动作完成后按配置回待机/倒地循环，重选动作前解除上次结束回调，不改作者共享动画资源。
- 成鸟在原生骨架包含眼睛皮肤时使用 canonical MonsterModel.SetupSkins 合并羽毛和眼睛，不创建真实战斗、宠物主人或修改遗物；替换骨架缺少该原生合同则不强套原版组合。
- 选人预览的场景检测与边界测量同时补充根 Sprite2D / AnimatedSprite2D，避免只有单个精灵根节点的外观被错误判为空。

## 验证

- 正式版引用 Release AnyCPU 构建零警告零错误，同一生产 DLL 在正式版 v0.107.1 与当前测试版 v0.113.1 通过 check-dual-branch.ps1（ABI、三模式、运行时安全、预览和商店生命周期）。
- 新 --test-extra-creatures 两端通过：实际分支分别显示 3 / 5 项；检查五份真实 PCK 场景及新增三项骨架导入目标，验证共用列表/选择写入与三条展示资源路径、事件清理、15 语言及帧动画副本合同。
- LogicTests 全部通过，新增五项登记、旧分支保留三项和新分支显示五项断言，保留原有两项动作约束。
- check-protected-characters.ps1 完整通过：十字军、两份贞德共 13 个真实变体、24 次战损调色及相关安全检查。
- 未启动或控制游戏。最终绘制、所有第三方皮肤的自定义动作及声音未做实机验证；不存在的动作不会伪造按钮。
