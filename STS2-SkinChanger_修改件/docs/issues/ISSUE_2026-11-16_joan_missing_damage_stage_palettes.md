# 1.0.33.1：贞德第二、三档战损保留变体调色

用户截图：Saber 王庭蓝第一档背景与预览都是黄发，第二、三档变回原色白发；其他变体同类。日志确认切档持续正常，同时作者启动只报告 palette ready: 9 pages。

静态核对实际作者 Palette.BuildPages：基础四页加上启动时 FileAccess.FileExists 判定存在的选人/手势/头像页。第二、三档是可选页，只在 Start 时建立，后续 ApplyNow 仅查询 Pages；若当时另一份同身份 SFW 包的资源可见，就不会登记第二、三档。真实可战损 PCK 确实包含 s1/s2/s3_charselect 每档的 index.png、1/2/3.png，所以重复 ApplyNow 不会自动补回漏页。

修复：保护区新增 StagePalettePages，在每次切档 ApplyNow 前检查当前档是否已登记。仅适用于已核对的 JoanofArcIroncladHpwear 合同；缺页时从所选包直接读取调色索引、三份配色及作者 shader，按作者非发光选人页合同创建材质，继承作者当前 _weights 后登记回原 Pages。后续作者 SetWeights/Tick 会自然更新新页，变体切换不再回到默认色。已存在页保持复用，不修改 SFW 包能力、不修改第三方 DLL/PCK。失败不登记半成品，仅清理未发布材质并报告日志；保留原有内存余量检查。

验证：
- 真实作者 DLL 的 Page 类型、MapPage 和四份 PresetWeights；模拟 9 页启动状态，四变体 24 次三档切换只补建两页，重复切换不新增材质，失败不发布半页。
- 真实两套包全部 13 个保护选项；可战损包四变体的三档共 12 份调色图片逐一验证存在且为 PNG，隔离图与预算验证保留。
- 更新既有切档边界测试，要求 ReapplyPalette 必须接入缺页检查；原保护断言全部保留。
- 完整保护脚本通过：十字军正式 CardPlay/Smite、变体/作用域、资源路径 200 次替换、预览/队列与退出安全。
- Release 0 警告 0 错误；未启动游戏，不将离线登记/资源合同测试称为实机 GPU 色彩验证。
