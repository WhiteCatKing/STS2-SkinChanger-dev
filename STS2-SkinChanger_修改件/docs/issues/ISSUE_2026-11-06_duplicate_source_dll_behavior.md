# 同 ID 差分包：无法执行自己的 DLL，依赖代码的皮肤错位

- 状态：**未解决**（已改为直接修包：n 版 DLL 程序集改名；待实机验证）
- 来源：作者本人实测 2026-11-06（商人 n 版 = Merchant2CuteII v1.4.1 差分包，与工坊 v1.6.0 同时安装）
- 关联：`issues/ISSUE_2026-09-15_merchant_model_top_left.md`（商人位置/缩放错到左上角）

## 现象

工坊 `Merchant2CuteII`（v1.6.0）与本地 `mods\商人n版`（v1.4.1，同 ID 差分包）同时安装时：

- 选工坊版：商人位置正确（`位置=(137.3, 223.3)，缩放=0.1800`）；
- 选 n 版：商人大约放大 2.6 倍并整体跑到屏幕左上角（`位置=(-1122.7, -396.7)，缩放=0.4701`，即原版变换）；
- 选 `商人“阿塔”`：正常（`位置=(125.0, 280.0)，缩放=0.1500`）。

## 根因

`godot.log` 启动阶段直接给出了原因：

```
[WARN] [SkinChanger] Merchant2CuteII 的差分包 DLL 与已加载程序集同名但内容不同；
       .NET 无法在游戏默认加载域中安全并存这两个行为程序集。为避免串用错误代码，
       当前差分包只接管可独立隔离的 PCK、图片、场景与卡面资源，不执行冲突 DLL。
[INFO] [SkinChanger] 已接管同 ID 皮肤来源：Merchant2CuteII::source:n-3cd9c892；…注册方式=仅内部差分。
```

两个包的程序集标识完全相同（都叫 `Merchant2CuteII`、同版本），内容不同。默认加载域里同标识只能存在一份，
所以差分包被有意设成“只供资源、不执行代码”（`ProviderAssembly.CanActivateBehavior = false`）。

而 `Merchant2CuteII` 的商人位置/缩放**只写在它的 `NMerchantButton._Ready` 前缀里**（`Position += (1260,620)`、`Scale = 0.18`）。
之前日志里能直接看到后果：n 版选中时 `ReplaySelectedNodeReadyPrefixes` 找不到它的运行时（提供者从未激活），静默返回空列表，
于是按钮保留原版场景值 `(-1122.7, -396.7) / 0.4701` —— 相对娘化骨骼应有的 0.18 恰好放大约 2.6 倍，位置又被推向左上。

也就是说：这不是“还原把变换撤掉”的那条路径，而是**差分包的代码根本没跑**。

## 修复（1.0.26.54 测试补丁）

既然差分包与主来源是同一套皮肤（同 ID、只差内容），就让**能执行的那一份程序集**继续提供行为：

1. 注册程序集时记录“同标识代表提供者”，差分包登记为它的行为别名（`ManagedSkinModLoader.BehaviorProviderAliases`、
   `ResolveBehaviorProviderId`）。
2. 计算活跃提供者集合时，差分包在可见范围内就把它的行为别名一并加入（`SkinService.GetActiveRuntimeProviders`），
   这样主来源不会被 `DeactivateProvidersExcept` 卸掉，反而会在差分包被选中时保持（或重新）激活。
3. 商人外观的所有重放（按钮前缀/后缀、库存、假商人）与设置绑定都改为用 `ResolveBehaviorProviderId(选中项)` 的 id，
   画面上再不会出现“资源是新包、代码从未运行”的组合；日志会写成
   `商人骨骼变换已应用：<选中项>（merchant，行为程序集来自同 ID 主来源 <别名>）位置=…，缩放=…`。
4. 之前那条“仍然选中同一提供者时保留骨骼变换”的保护也改为按行为别名判断，避免别名场景下被误还原。

修复不改动任何第三方 Mod 的文件：n 包的 JSON/PCK/DLL 原样保留，两个包仍然可以同时安装、下拉里分别选择。

## 待实机验证

- 同时安装工坊 v1.6.0 与 n 版，选中 n 版：商人应正常大小、正常位置；日志出现
  `商人骨骼变换已应用：Merchant2CuteII::source:n-…（merchant，行为程序集来自同 ID 主来源 Merchant2CuteII::source:3748331824）位置=(137.3, 223.3)，缩放=(0.1800, 0.1800)`。
- 三个商人皮肤来回切换、进出商店、假商人事件各一次。
- 只安装 n 版（不装工坊版）时，它自己就是代表提供者，行为别名不生效，同样应正常（此前也能正常）。

## 已知边界

- 若差分包的骨骼确实需要与主来源不同的位置/缩放（即作者改过模型比例），借用主来源代码仍是主来源的数值，
  这种情况下需要把差分包改成独立程序集名（改 DLL 元数据），不在本补丁范围。
- 同理适用于任何“同 ID 差分包、外观依赖自己 DLL”的皮肤，不只是商人。
