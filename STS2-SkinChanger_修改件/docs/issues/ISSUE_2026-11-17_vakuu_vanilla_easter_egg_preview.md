# 2026-11-17：1.0.33.2 瓦库官方原图/彩蛋选项及图鉴预览

用户报告其他图鉴瓦库游戏默认预览为空，并要求原图仍归游戏默认、彩蛋为瓦库专属新选项，沿用黄色与菱形样式。

原因：新版瓦库背景场景的图片改由 ConfigureBackgroundScene 动态赋值，图鉴只 Instantiate 场景，没有事件状态下的原生赋图流程，默认 TextureRect 保持空白。

修改：
- 新增内置选择 __vakuu_default_easter_egg__，仅当当前游戏确实有 normal/angry 两张官方图时注册到 vakuu。没有外部皮肤包也可选择，不冒充第三方 provider。
- 默认预览明确使用 res://images/ancients/vakuu_placeholder.png，彩蛋使用 vakuu_angry.png。通过基线隔离入口加载，避免取到之前散图 provider 留在公共缓存的图。
- 新项紧跟游戏默认且只出现一次；显示 ◈游戏默认彩蛋，复用默认前缀和黄色强调样式，15 语言同步。
- 使用现有事务保存/重载。排除分类优先级候选，避免无意自动选中彩蛋。
- 保留原生 ConfigureBackgroundScene 和进度逻辑，Postfix 仅为显式官方选择固定图片；跟随分类保持官方判定，第三方图片选择不覆盖。图鉴直接赋所选官方图，不调用含进度操作的事件配置回调。
- 保留此前外部散图隐藏 TextureRect 修复及战士保护功能。

验证：实际游戏 PCK 两张官方图及隔离根存在；无外部 mod 时仍有瓦库专属唯一彩蛋项、无其他先古泄漏；选择事务与 JSON 重载；分类列表不含内置项；15 语言默认前缀及统一强调策略。既有瓦库散图合同、先古卡牌优先级通过，保护脚本覆盖十字军/贞德、资源路径、预览/队列与退出安全。Release 0 警告 0 错误。

没有启动或控制游戏，字体最终渲染与场景显示未实机验证。内部版本 1.0.33.2，公开版本仍为 1.0.33；按既有流程三文件四处核对哈希并推送 main/标签，本轮不发布工坊。
