# #241 响木天音选角按钮串图

基线 `fix/1.0.36-stability` · `a1f2a99`，工作区保留 #235、#239。

## 定位

天音 0.1.0 的正常、锁定头像 getter 和路径补丁都借用了战士的 `char_select_ironclad*.png`。其按钮 `Refresh` 另有一条把天音自己的私有贴图写入 `%Icon` 的路径，玩家日志 7196 行证实普通头像曾解码。日志还记录了贞德原包的高优先级挂载。贞德的 `.import` 在同一个战士路径上可见时，天音的 getter 就会取得战士的图。

切换器在选中天音后进入未管理模型分支，`RefreshAllCharacterButtonIcons` 原先仍重刷所有按钮。天音没有对应选装分组，于是这次刷新退回它的 getter，并由切换器的 `SetCharacterButtonIcon` 写回 `%Icon`。这条路径能盖过天音先前的私有图写入。原始日志可确认这两条路径曾出现，未采集现场逐次 Texture 写入的跟踪，因此不能从那份截图倒推同帧的最后一条回调。

## 修复

- 角色按钮初始化时，为确切的 `MaidenSuccubusCharacter` 安装普通和锁定的头像及路径 getter。离线实包确认路径由 RitsuLib 的闭合模板子类重写，补丁落在实际声明的实现。两种状态各自使用天音 PCK 的私有导入图。切换器批量刷新时保留无皮肤分组的内容角色自己的按钮。
- 战士等角色的选角头像由自己的分组从私有运行资源按选择加载。共享校正包保留原版或原生内容来源。完整提供者 PCK 挂载前过滤选角头像的规范入口及其原版导入载荷，保留私有图和其他外观资源。过滤后的 PCK 走已有磁盘预算和缓存，可复用。别名运行包及 Godot 缓存绑定也保留这条公开路径边界。
