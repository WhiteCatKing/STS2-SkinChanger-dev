切换器改动集中在 `SkinCatalog` 的运行时分类与资源隔离、`SkinService` 的可见动画启用时机，以及 `ContextualSkinControls` 的图鉴选择入口。动态场景复用已有的 Godot 二进制依赖改写，让三段场景直接引用各自的私有贴图，不占用原版场景或贴图路径。

正式版和测试版引用构建通过。逻辑测试、两种引用的完整运行时测试、十字军和两套贞德实包回归通过。残杀千足虫专项使用本机游戏包、动态包和三套 Kiteseven 实包，逐项检查首次切换对四个分组的提交、动态回调启用条件、静态资源来源和动态场景的私有依赖。动态包的 128 份内嵌动画资源逐字节比较一致，改写方法已通过测试版引用的载入和编译检查。

需实机确认。重启后在图鉴选中动态版并点一次「扭动」，预期第一下即播放。然后逐一换到三套静态皮肤及「游戏默认」，每次只点一下，预期三段同时换对、无动态残影。切回动态版点一次「接续」，预期动画立即可用；关闭再打开图鉴，也重复一次。局内对上残杀千足虫时，做一次动态版 → 原皮 → 动态版，确认链条与三段换装同步，并保留扭动、死亡和接续的动作。

## 首次入场残留与缩放

- 复测日志第 2342、2417、2491 行报告原版骨骼挂点被复制到普通图片节点，第 2373、2447、2521 行记录原版特效跟着启动并报错。部分静态选择也重现同样错误，第 2715 和 2835 行可见。
- 补齐场景节点时跳过不能附在普通图片上的原版骨骼和千足虫特效节点。边界、意图和中心标记仍可补齐。游戏攻击主动生成的落石仍按原动作执行。
- 同款静态版在图鉴里围绕中段同时缩放三段和站位。动态版 0.4.11 在比例改变时重新校准图鉴阵型和局内链条。图鉴若在动画控制器收到第一帧前点动作，先完成初始校准再播放。
- 实机复测：重启后，首次打开残杀千足虫图鉴时分别看动态版及同款静态版。预期加载时没有原版骨骼挂点报错。每套滑到 50%、150%、100%，检查身体和连接位置；动态版分别点「扭动」和「接续」。局内对上残杀千足虫时，动态版在 50%、150% 各打一轮，确认链条、攻击、受击和接续。按住原位对比及回到 100% 后，模型应回到原尺寸。
