# 协作者指南（zuimao-feng）

本文件说明如何在本地跑起来《杀戮尖塔 2》皮肤切换器（Gurio.SkinChanger）的源码、改代码、验证、提交。

## 1. 仓库与环境

- 仓库（private）：<https://github.com/WhiteCatKing/STS2-SkinChanger>
- 先接受邀请：<https://github.com/WhiteCatKing/STS2-SkinChanger/invitations>
- 需要：Windows、.NET 9 SDK、游戏本体（Steam 版《Slay the Spire 2》）

```powershell
git clone https://github.com/WhiteCatKing/STS2-SkinChanger.git
cd STS2-SkinChanger
```

如果 `git` 连不上 GitHub（本机走代理），先执行一次：

```powershell
git config http.proxy http://127.0.0.1:7890
```

不需要代理时用 `git config --unset http.proxy` 取消。

## 2. 目录约定（重要）

| 目录 | 用途 | 能否修改 |
| --- | --- | --- |
| `STS2-SkinChanger_修改件/` | **唯一可改的源码树** | 可以 |
| `STS2-SkinChanger_修改件/源文件（坚决不能动）/` | 上游原始快照，仅作对照 | **禁止** |
| `STS2-SkinChanger_备份_*/`、`_mods_disabled_*/` | 备份与被停用的第三方包 | 不要提交 |
| `STS2_Work/workshop_content_1.0.20/` | 创意工坊上传内容（3 个文件） | 只放产物 |
| `docs/` | 文档 | 可以 |

## 3. 构建

必须把 `GameAssemblyDir` 指向真实游戏目录（不同版本都要用这个参数，v0.107 与 v0.113 均可编译）：

```powershell
cd STS2-SkinChanger_修改件
dotnet build STS2SkinChanger/STS2SkinChanger.csproj -c Release --no-incremental `
  -p:GameAssemblyDir="D:\steam\steamapps\common\Slay the Spire 2\data_sts2_windows_x86_64"
```

产物：`STS2SkinChanger/bin/Release/Gurio.SkinChanger.dll`。

## 4. 测试

```powershell
dotnet run --project tests/STS2SkinChanger.LogicTests -c Release `
  -p:GameAssemblyDir="D:\steam\steamapps\common\Slay the Spire 2\data_sts2_windows_x86_64"
```

末行必须是 `Skin Changer logic policy tests passed.`，否则视为失败。
注意：**测试命令也必须带 `-p:GameAssemblyDir`**，否则 `tests` 项目引用的 `compat/ThunninoiSkinManagerCompat` 会解析不到 `sts2.dll`，报 `CS0246 ModelId`。

## 5. 本地部署（自测用）

先退出游戏（`mods` 下 DLL 被占用会复制失败），再覆盖：

```powershell
$dll = "STS2-SkinChanger_修改件\STS2SkinChanger\bin\Release\Gurio.SkinChanger.dll"
Copy-Item $dll "D:\steam\steamapps\common\Slay the Spire 2\mods\STS2皮肤切换器_mod测试版安装包\Gurio.SkinChanger.dll" -Force
```

日志：`%APPDATA%\SlayTheSpire2\logs\godot.log`
配置：`%APPDATA%\SlayTheSpire2\Gurio.SkinChanger\skin_changer.json`
启动卡住时看：`%APPDATA%\SlayTheSpire2\Gurio.SkinChanger\startup_hang.txt`（我方看门狗写的）

## 6. 改代码的规矩

- **只改与任务相关的文件**，不顺手重构、不改无关格式。
- 修 Bug 先定位根因，不在症状上层层加补丁；一个数据只允许一个真源。
- 版本号共 4 处，每次发版一起改：
  `STS2SkinChanger/Entry.cs`、`STS2SkinChanger/STS2SkinChanger.csproj`、`STS2SkinChanger/SkinChanger.json`、`workshop/workshop.json`
  （`SkinChanger.json` 里 `version` 是发布版号、`internal_test_version` 是内测版号，不要混用）
- 改动要在 `CHANGELOG.md` 顶层加一节，写明症状/根因/修法。
- **提交信息用中文**，第一行是「版本号 + 一句话」，正文写清根因与影响面。

## 7. 提交与推送

```powershell
git add -A
git commit -m "1.0.32.x 修 xxx"
git push origin main
```

- 默认分支是 **`main`**（不是 `master`）。
- 不要 `git push --force`。
- 大文件（`*.zip`、`*.bundle`、备份目录）已在 `.gitignore` 里排除，不要强行加入。

## 8. 创意工坊

**只有作者（WhiteCatKing）发布**。协作者不要动 `workshop/` 的内容与 Steam 上传流程。

## 9. 遇到问题

- 构建报 `CS0246 ModelId`：漏了 `-p:GameAssemblyDir`。
- 游戏里「所有皮肤都检测不到」：先确认 DLL 版本与游戏版本匹配（v0.107.1 正式版 / v0.113.0 测试版），并把 `godot.log` 一起带上。
- 启动卡在黑屏：等 60–90 秒看是否自己进主菜单；超过 3 分钟仍无响应，把 `startup_hang.txt` 与 `godot.log` 一起发。
