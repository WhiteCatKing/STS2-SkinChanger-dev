## 3. 改动须知

### 以后写代码要遵守的（门禁会查）

- **界面注入**：挂在游戏节点生命周期（`_Ready` / `_EnterTree` / `OnSubmenuOpened` / `OnSubmenuClosed`）或界面回调上的新 Harmony 钩子，用 `UiInjectionGuard.Run(...)` 包起来。有意不包的，在 `UiInjectionGuardTests` 的白名单里写原因，并更新预期数量。
- **延迟调用**：新的 `CallDeferred`、多帧轮询、重试点，走 `DeferredDispatch.CallDeferred` / `WrapCallback` / `RunTracked`；逐帧等待用 `WrapPollCallback` / `RunTrackedPoll`。每处写六项注释：原触发时机、最早可执行帧、顺序依赖、能否合并、重试上限、取消条件。
- **全局写入**：改 `PreloadManager.Cache`、`ResourceLoader` 缓存、挂载 PCK 这类全局状态，走 `GlobalResourceWrites`，按编号 A01–A32 记账。规则见 `STS2-SkinChanger_修改件/docs/agents/global-write-policy.md`。
- **修法要对任意 Mod 组合成立**：尽量不按包名或工坊 ID 写特判；确实需要的第三方兼容，在注释里写明。
- **门禁**：改完跑 `tools\run-gates.ps1`，正式版和测试版两种引用各跑一遍，现在是 43 项。动到共享入口或受保护角色时，再跑 `tools\check-protected-characters.ps1`。
- **不许丢的修复**：`STS2-SkinChanger_修改件/docs/agents/maintenance-rules.md` 里新加了「1.0.41.23 新增」一段，改到相关代码时照着保留。

### 行为上的变化（玩家能感觉到的）

- **禁用卡图 Mod**：放在独立文件夹里的卡图 Mod 被禁用后不再应用，已选的卡图回到默认，存档原值保留，重新启用后自动恢复。启用和停用的 Mod 清单混放在同一文件夹、又带卡图包时，**不按包判断归属**，每次启动弹一次提示，请玩家分开放。
- **只改文本的事件包**：保留在下拉里，标「（仅文本）」，选中时不再联动整包外观，也不再打包重载原版事件图。
- **假商人背景微调（U/O/I/J/K/L）**：改成调试开关，只有 `STS2SC_DEBUG=1` 时才挂上。你的 1.0.41.21 / 1.0.42 维修日志里还写着这组按键，请改成"调试用"或删掉。如果你已经调出满意的数值，建议直接写成默认值。
