# 小红帽铁甲选人闪退诊断包

适用游戏测试版 v0.113.1。关闭游戏，备份现有皮肤切换器 DLL，再用 SkinChanger-test 里的 DLL 覆盖同一个安装目录，避免同时加载两份切换器。现有清单可保留。本包含当前本地小红帽局内同步修复和专用日志，未改选人/资源加载判定。

在云原来能复现的模组环境中，仅启用小红帽铁甲包（停用小红帽骨妹包），关闭该角色的其他皮肤干预，铁甲选游戏默认，冷启动后进单人选人界面点铁甲一次。保存完整 godot.log；若有转储，同时记录该次转储的文件名。对照组仅停用小红帽铁甲包，其余环境相同。

[RH-select] watching 表示观察器安装成功，enter / exit 表示实际进入 / 返回；若未装上观察器，不以缺少 enter 判定未执行。[RH-pack] 记录铁甲独立运行包路径、每个条目的字节数及 SHA256。可复制日志里对应的生成包供本地比对。

overlay-files.txt 是本机离线重建的对照清单：以原版铁甲选人背景和转场材质为根，得到 11 个独立资源、24 个文件，约 11927 KiB；含原版背景、骨骼、图集、转场和两张粒子贴图及导入映射。对照清单没有小红帽命名空间。云报告是约 8955 KiB，因此此重建不能替代云那份原始运行包。
