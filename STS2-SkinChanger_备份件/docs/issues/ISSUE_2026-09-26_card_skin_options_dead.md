# 卡牌皮肤选项失效

- 状态：**未解决**
- 来源：留言 Uncle Bob 2026-09-26（英文：“The options to change card skins seems to have stopped working for me”）
- 收录：2026-11-03

## 现象

卡牌皮肤选择/切换入口失效；反馈者未说明是下拉框不出现、点选无反应，还是切换后不生效。

## 初步判断

- 可能是卡牌组识别在 1.0.19.x 改动后丢失（日志里“识别 N 个外观组”与卡牌组数量可核对）；
- 也可能是该玩家的卡图来源是第三方 Mod，走的是“按 Mod 优先级”路径而不是单卡下拉；
- 不排除与 `CardSkinControls` 的重建/焦点逻辑有关。

## 下一步

1. 要反馈者日志与游戏版本，确认卡牌组是否被识别、是否有 `CardSkinControls` 异常。
2. 本地用 1.0.21 复现：只开一张卡图 Mod，看单卡下拉是否正常。
3. 若只在特定 Mod 组合失效，检查 `CardSkinPriorities` 与来源归属。

## 关联

- 与“按 Mod 粒度禁用卡面替换”（已定案为卡牌“Mod 优先级”单表）不是同一问题。
