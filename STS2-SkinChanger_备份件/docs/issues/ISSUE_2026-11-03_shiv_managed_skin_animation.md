# 受管皮肤 Shiv 与普通攻击同动画

- 状态：**已解决**
- 来源：白猫 2026-11-03 实机反馈（狐猎等只有 shiv 动作的骨架）
- 收录：2026-11-04

## 现象

使用受管皮肤时，Shiv（小刀）攻击播放的是普通攻击动作，和 `attack` 共用同一段动画，导致动作不对。

## 原因

受管皮肤动画桥的 Shiv 路由只按普通攻击键回退，没有优先匹配骨架里实际存在的 `shiv` 动作。

## 解决

- 版本：1.0.21（2026-11-03）
- Shiv 路由改为优先 `shiv`，再依次回退 `attack2`、`attack_2`、`attack1`、`attack`；
- 已随 1.0.24 工坊版本发布。

## 关联

- 见 `COMPLETED_FIXED.md` 的 1.0.21 条目。
