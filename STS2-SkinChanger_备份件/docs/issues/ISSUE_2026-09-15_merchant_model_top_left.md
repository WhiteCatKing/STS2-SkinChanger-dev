# 商人娘化模型跑到左上角 / 连续进商店错位

- 状态：**未解决**
- 来源：留言 命 2026-09-15（“另一个娘化总会跑到左上角”）；讨论区 风色 2026-09-06「连续进入商店房间会导致商人模型错位，出现在左上角」（主题已被删除，只剩墓碑）
- 收录：2026-11-03

## 现象

商人娘化皮肤（至少“阿塔”系列与另一个娘化包）在连续进入商店房间后，模型位置错到屏幕左上角；有时只是位置不对，有时是换肤后没恢复。

## 初步判断

- 商人场景的 Spine 节点位置/缩放没有在重建覆盖包后重置；
- 与 `Ui/MerchantRuntimeAppearance.cs`、`MerchantRoomPrewarmPatch`（1.0.19.6 商店预读）可能相关：预读/重建时缓存了旧节点或旧偏移；
- 也可能与 `_background`/父节点引用在场景释放后仍指向旧节点有关（帝皇蟹曾有同类问题，见 `COMPLETED_FIXED.md`）。

## 下一步

1. 复现：连续进出商店 3 次以上，记录模型 `Position/Scale` 与父节点。
2. 检查商人外观应用时是否每次从基线恢复位置，而不是依赖上次缓存。
3. 对照帝皇蟹的 `KaiserCrabSkinRefreshPatch` 修复方式，补商人场景的刷新/复位。

## 关联

- 与 F21（商人皮肤换不了/每次重启还原）不是同一问题：F21 是持久化/接管路径，这里是运行时位置错位。
